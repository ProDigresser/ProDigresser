## What I build

- End-to-end product integrations, from technical discovery and architecture through implementation, rollout, and documentation.
- Go services and APIs that connect third-party platforms, cloud services, and on-premises access-control systems.
- Secure identity experiences: Microsoft Entra ID, enterprise SSO, MFA, TOTP, session management, and web/mobile authentication flows.
- Connected product experiences, including React Native, BLE unlocking, digital passes, event-driven feedback, and physical access-control hardware.
- Workflow tooling that replaces manual operations with clear rules, permissions, approvals, and useful interfaces.
